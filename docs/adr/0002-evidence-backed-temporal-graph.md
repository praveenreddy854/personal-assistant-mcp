# Evidence-backed temporal claims and derived memory levels

Represent memory as a generic graph of entities and source-backed claims, with separate effective and recorded times. Corrections share a lineage; real life transitions establish a new period and lineage, so correcting a mistake does not imply that it was historically true, and forgetting one residence need not erase every former residence. Generate L0/L1/L2 views from the same approved records instead of maintaining independent stores whose copies could diverge or survive deletion.
